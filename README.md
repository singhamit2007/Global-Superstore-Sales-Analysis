# Global Superstore Sales Analysis

## Project Overview

This is a Week 1 Data Science project based on the Global Superstore 2016 dataset.

The project uses Microsoft Excel to perform data analysis, Pivot Table summarization, and dashboard visualization to understand sales performance.

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Data Cleaning
- Data Visualization

## Analysis Performed

The project analyzes sales performance through:

1. Total Revenue
2. Sales by Category
3. Yearly Sales Trends
4. Revenue by Customer Segment

## Key Result

**Total Revenue: $12,642,501.91**

## Dashboard

The Excel dashboard provides a visual summary of the sales performance using charts and a key revenue indicator.

The dashboard includes:

- Total Revenue
- Sales by Category
- Yearly Sales Trend
- Revenue by Customer Segment

## Dataset

The project uses the Global Superstore 2016 dataset.

The main dataset contains order, customer, product, sales, quantity, discount, profit, shipping, and other related information.

## Note

The provided dataset does not contain a **Department** field.

Therefore, **Customer Segment** was used as the available business-level grouping for revenue analysis.
